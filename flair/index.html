Un explorateur de fichiers, un éditeur de code et un navigateur pour Linux.

flair, Flair Code et Flair Web sont des applications natives pour Arch Linux, écrites en C++ et Qt Quick. Elles partagent leur couleur, leurs réglages et leur assistant IA, qui peut tourner sur votre machine.

flair, Projets / jardin-partage

flair

Un explorateur de fichiers qui lit, cherche et range avec l'IA, entièrement au clavier.

  • EspaceAperçuUne page HTML s'affiche rendue, le reste (texte, code, PDF) est résumé.
  • /Recherche par le sens« la facture d'électricité de l'an dernier », sans connaître le nom du fichier.
  • :Ranger en une phrase« range les captures par mois » donne un plan que vous validez avant que rien ne bouge.
  • Les plans ne suppriment et n'écrasent rien, et Ctrl+Z les annule.
  • Statut Git dans la liste, vos dépôts GitHub dans la barre latérale.
  • Images, musique et vidéos s'ouvrent dans flair.

Flair Code

Un éditeur de code avec un assistant IA, l'aperçu en direct et une palette de commandes.

  • CtrlKModifier avec l'IADécrivez le changement, l'avant et l'après s'affichent, Ctrl+Entrée accepte.
  • CtrlLDiscuter du fichierAvec Claude, OpenAI, Gemini ou un modèle local (LM Studio, Ollama).
  • CtrlMajVAperçu en directHTML et SVG rendus à chaque frappe, Markdown mis en forme.
  • Coloration de C/C++, Python, Rust, Go, QML et onze autres langages.
  • Enregistrement atomique : un fichier n'est jamais écrit à moitié.
  • Un fichier modifié ailleurs se recharge, sauf si vous l'avez modifié aussi.

Flair Web

Un navigateur avec le moteur de recherche de votre choix, un bouclier anti-pistage et les extensions Chrome.

  • CtrlKChoisir le moteurDuckDuckGo, Startpage, Brave, Qwant, Google… ou les vôtres. « yt chats » cherche sur YouTube.
  • F9Mode lectureL'article seul, avec sa police, sa largeur et son thème.
  • CtrlMajAAssistant de pageRésumer, traduire ou poser une question sur la page.
  • Le bouclier bloque pubs et traceurs, et compte ce qu'il bloque sur chaque page.
  • Extensions Chrome : uBlock Origin Lite, Bitwarden et Dark Reader testés.
  • Les onglets privés ne laissent rien sur le disque.

Captures réelles des applications, en développement. Les flèches du clavier passent d'une app à l'autre.

Trois apps, une seule façon de faire.

Chaque application s'utilise seule. Installées ensemble, elles se reconnaissent.

Une couleur pour les trois

La couleur d'accent choisie dans flair s'applique à Flair Code et Flair Web, jusqu'à leurs icônes dans le lanceur. Elle peut aussi suivre le thème de Vex.

Des réglages partagés

La clé d'API saisie dans flair sert aux deux autres. Les réglages restent dans des fichiers lisibles, comme ~/.config/flair/flair.conf, en mode 0600.

L'IA chez vous, si vous voulez

Un modèle local (LM Studio, Ollama) ou votre propre clé Claude, OpenAI ou Gemini. La recherche par le sens de flair calcule toujours ses index sur votre machine. Rien ne passe par un serveur de flair : il n'y en a pas.

Elles s'appellent entre elles

flair ouvre le code dans Flair Code et les pages dans Flair Web. Un téléchargement de Flair Web s'affiche dans flair en un clic.

Comment c'est fait

Pas de page web déguisée en application : l'interface est en Qt Quick, le reste en C++. Les trois apps démarrent vite et restent légères, sauf Flair Web, qui embarque le moteur Chromium de Qt WebEngine.

Chacune a ses tests unitaires, ses réglages dans un fichier texte et un paquet Arch construit par un PKGBUILD.

Questions

Qui fait la suite flair ?

La suite flair est créée par vex, développeur frontend indépendant. Le reste de son travail est sur son portfolio.

Où la télécharger ?

Sur GitHub : chaque app a sa page de versions avec le paquet Arch et sa somme de contrôle, et son code source sous licence MIT (flair, Flair Code, Flair Web). Une question ou un bug : écrivez un mail ou ouvrez une issue sur GitHub.

Sur quel système fonctionnent-elles ?

Sur Arch Linux avec Qt 6, sous Wayland ou X11. Sur Vex, la distribution de vex, elles suivent en plus le thème du bureau.

Faut-il un compte ou un abonnement ?

Non. Les apps fonctionnent sans IA. Pour l'assistant, vous utilisez un modèle local gratuit ou la clé de votre propre fournisseur, qui vous facture directement.

Mes fichiers partent-ils sur internet ?

Pas avec un modèle local. Avec une IA en ligne, seul ce que vous lui demandez de lire part chez le fournisseur choisi : un fichier à résumer, une sélection de code, une page web.

Les index de la recherche par le sens sont toujours calculés sur votre machine.

Le code sera-t-il ouvert ?

Oui, sous licence MIT, publié en même temps que les paquets.
