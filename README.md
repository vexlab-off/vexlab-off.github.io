# vexlab-off.github.io

L'hébergement de Vex Labs sur GitHub Pages :

- `/` renvoie vers le portfolio : https://vexlab-off.github.io/vex-portfolio/ (dépôt `vex-portfolio`) ;
- `/flair/` : la page de la suite flair ;
- `/arch/` : le dépôt pacman de la suite flair (`Server = https://vexlab-off.github.io/arch/$arch`).

Pour publier de nouveaux paquets : les copier dans `arch/x86_64/`, mettre à jour la base avec `repo-add`, puis pousser.
